포켓톡 Windows 다운로드

이 PC에서 포켓톡을 실행하세요. 채팅, 일정, 영수증과 계정 정보는 내 PC에 저장됩니다.

Windows 실행 파일 다운로드 Ollama · API 설정 키트 다운로드
Windows x64 · 약 210 MB · 로컬 AI 자동 준비

설정 키트 사용하기

독립 실행 파일 PocketTok-SetupKit.exe는 약 25 MB입니다. 새 PC에서 실행하면 Ollama와 두 모델을 확인하고 필요한 항목을 준비합니다. 전체를 처음 받으면 약 10 GB를 다운로드하므로 여유 공간 12 GB 이상을 권장합니다.

  1. 키트가 기존 카카오·기상청·TMAP 키를 자동으로 찾습니다. 미등록 서비스는 발급받은 키를 입력하고 입력한 키 저장을 누르세요.
  2. 기존 PC의 설정을 옮기려면 이동용 키트 만들기에서 암호를 정하세요. 만들어진 PocketTok-Transfer 폴더를 통째로 옮겨 새 PC에서 실행하고 암호를 한 번 입력하세요.
  3. API 실제 연결 검사로 등록된 서비스에 시험 요청을 보낼 수 있습니다. 카카오 지도 JavaScript 키는 포켓톡 브라우저에서 허용 도메인을 확인하세요.

포켓톡이 이미 열려 있으면 기존 Ollama 상태를 확인합니다. 새 키를 저장한 뒤에는 포켓톡을 다시 실행하세요.

처음 실행하기

  1. 이전 버전을 사용 중이면 알림 영역에서 종료한 뒤, 다운로드한 PocketTok-Ready.exe를 두 번 클릭하세요. 첫 실행 때 약 621 MB의 구성 파일을 풉니다.
  2. 기본 브라우저에 http://127.0.0.1:53127/home이 열리면 이 PC에서 사용할 계정을 만드세요.
  3. 앱을 종료하려면 Windows 알림 영역의 포켓톡 아이콘을 오른쪽 클릭하고 포켓톡 종료를 선택하세요.

데이터 저장 위치는 %LOCALAPPDATA%\PocketTokLocal\data입니다. 한글 OCR이 포함되어 있습니다.

로컬 AI 자동 준비

포켓톡이 이 PC의 Ollama를 시작하고 영수증·방 AI에 필요한 모델을 받습니다. 모두 처음 받는 PC는 다운로드가 약 10 GB이며, 여유 공간은 12 GB 이상을 권장합니다. 이미 설치된 모델은 재사용합니다. 알림 영역의 포켓톡 아이콘에서 AI 준비 상태를 확인하세요.

다른 PC에 API 키 가져오기

  1. 원래 PC에서 이 버전을 열고 포켓톡 알림 영역 메뉴의 API 키 내보내기를 선택하세요. 암호를 정해 PocketTok.keys를 저장하세요.
  2. 새 PC로 키 파일을 옮겨 EXE와 같은 폴더에 놓고 실행하세요. 암호를 한 번 입력하면 그 Windows 계정에 저장됩니다.
  3. 이미 실행 중이면 API 키 가져오기를 선택하고 포켓톡을 종료한 뒤 다시 여세요.

카카오·기상청·TMAP 키를 지원합니다. 이 PC의 Windows 환경 변수와 포켓톡에 저장된 키도 자동으로 읽습니다. 카카오 지도를 사용하려면 해당 앱의 허용 도메인에 http://127.0.0.1:53127을 등록하세요.
